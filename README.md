# Programação Backend I com Banco de Dados

Material didático de introdução ao desenvolvimento backend com **Ruby on Rails** e banco
de dados relacional.

## Estrutura

Organizado nas três unidades da disciplina: `Unidade01`, `Unidade02` e `Unidade03` —
fundamentos do framework, models e migrations, e CRUD completo.

## Conceitos cobertos

- Estrutura de um projeto Rails e o padrão MVC
- **Migrations**: versionar o esquema do banco junto com o código
- **Active Record**: models, associações e validações
- CRUD via controllers e views
- Rotas RESTful

## Por que Rails para ensinar backend

Rails impõe convenção. Isso limita a liberdade — e é exatamente o ponto quando o objetivo é
ensinar: o aluno não gasta as primeiras semanas decidindo onde cada arquivo vai, e enxerga
a separação entre model, controller e view antes de ter que projetá-la sozinho.

## Como rodar

```bash
bundle install
rails db:migrate
rails server
```

Aplicação em `http://localhost:3000`.
